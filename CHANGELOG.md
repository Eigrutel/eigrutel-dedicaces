# Historique / Changelog

## 1.0.0 — 2026-09-22

Première version stable publique de **Dédicaces**.

- Partage d’une fiche JSON : export avec post-it/documents facultatifs, import additif avec confirmation et avertissement de doublon. / Single-event JSON sharing with optional notes and attachments, additive import and duplicate warning.

- Interface français / anglais avec choix de langue mémorisé.
- Fiches pastel, quatre colonnes sur grand écran, affichage adaptatif.
- Informations festival, site web, contacts, transports, billets et hôtel.
- Post-it personnel et pièces jointes incluses dans les sauvegardes.
- Emploi du temps hebdomadaire et calendriers mensuels à défilement continu.
- Agenda compact : les sept jours et les 24 heures sont affichés sur la largeur disponible, mobile compris.
- Champs date et heure contraints à leur colonne pour éviter les débordements.
- Sauvegarde locale IndexedDB et import / export JSON compatible avec les versions de travail.
- Code mis en forme, commenté et accompagné de la documentation du dépôt.
- Icônes navigateur et Apple dans `favicon/`.

Les numéros des versions de travail ne constituent pas des releases publiques. Cette livraison inaugure la version stable **1.0.0**.

### English

First public stable release: bilingual French / English interface, pastel event cards, contacts and websites, travel, hotels, signing sessions, sticky notes, attachments, weekly timetable and continuously scrolling month calendars. Local IndexedDB storage and portable JSON backups remain compatible with development versions. Source is formatted and commented; repository documentation and favicon are included.
