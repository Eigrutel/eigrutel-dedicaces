## Description de la release

Première version publique stable de Dédicaces, l’agenda libre et autonome d’Eigrutel Lab pour organiser ses festivals, dédicaces et déplacements.

Interface français / anglais, fiches colorées, contacts et sites web, transports et billets, hôtel, emploi du temps hebdomadaire, calendriers mensuels à défilement continu, post-it personnel, pièces jointes, impression et sauvegardes JSON. Les données restent sur l’appareil. Compatible avec les sauvegardes des versions de travail précédentes.

Conception et développement : Simon Léturgie — Eigrutel BD Academy / Eigrutel Lab.

Code : GNU AGPL v3.0 ou ultérieure. Documentation et modèles : CC BY-SA 4.0 sauf mention contraire. Marques et logos Eigrutel réservés.

### English release description

First public stable release of Dédicaces, Eigrutel Lab’s free, standalone planner for book signings, festivals and travel.

French / English interface, coloured event cards, contacts and websites, travel and tickets, hotels, weekly timetable, continuously scrolling month calendars, personal sticky notes, attachments, printing and JSON backups. Data stays on your device. Compatible with backups from earlier development versions.

Designed and developed by Simon Léturgie — Eigrutel BD Academy / Eigrutel Lab. Code: AGPL-3.0-or-later. Documentation and templates: CC BY-SA 4.0 unless otherwise stated. Eigrutel trademarks and logos reserved.

## GitHub Pages

Après dépôt des fichiers sur la branche `main`, choisir **Settings → Pages → Deploy from a branch → main → / (root)**. `index.html` est le point d’entrée ; son bouton ouvre `dedicaces.html`.

Pour mettre à jour le site existant, remplacer `dedicaces.html` à la même adresse et conserver `favicon/favdedic.png`. Faire une sauvegarde JSON avant l’opération.
